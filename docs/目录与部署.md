# 统一目录与部署

2026-10-31 起，开发板上本项目的源码、Git 数据、Python 环境、模型与实验输出统一放在：

```text
/root/mini-llm-ascend/
├── .git/                 标准 Git 仓库，保留全部提交历史
├── .venv/                Python 环境，复用板载 torch / torch_npu
├── models/Qwen3-0.6B/    模型与 tokenizer
├── results/              基准输出和本地实验文件
├── mini_llm_ascend/       M1 模型前向、连续 KV 与生成循环
├── bench/                环境探测、HF 基线与 M1 运行/对拍入口
├── tests/                测试
├── scripts/              部署辅助
├── configs/              引擎配置草案
├── docs/                 文档和归档实验
└── .migration-backup/    本次迁移的 Git bundle、旧配置和启动脚本备份
```

`.git`、`.venv` 和 `.migration-backup` 是隐藏目录，使用 `ls -la` 查看。

日常只需进入这一个目录：

```bash
cd /root/mini-llm-ascend
source /usr/local/Ascend/ascend-toolkit/set_env.sh
source .venv/bin/activate

git status
python -m bench.probe_env --device npu
python -m bench.baseline --model ./models/Qwen3-0.6B --device npu \
  --max-new-tokens 8 --fixed-length --warmup 1 --runs 3
```

项目环境和模型不会随源码提交到 GitHub。系统 CANN、板载 Python/torch 以及设备共享编译缓存仍由系统管理，不属于可搬进项目的独立文件。

## 推送到开发板

笔记本仓库的 `origin` 指向 GitHub，`board` 指向：

```text
root@YOUR_BOARD_HOST:/root/mini-llm-ascend
```

已有旧远端时执行 `git remote set-url board root@YOUR_BOARD_HOST:/root/mini-llm-ascend`。推送命令仍为 `git push board main`。

板端采用普通仓库与 `receive.denyCurrentBranch=updateInstead`，不再依赖分散的裸仓库和强制 checkout 钩子。可直接在板端执行 `git log`、`git status`、`git diff`。已跟踪文件有未提交改动时，Git 会拒绝自动部署；先检查并保存这些改动。
